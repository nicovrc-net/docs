# nicovideo.life / nicovrc.netの機能

nicovideo.lifeは、多岐にわたるプラットフォームの動画コンテンツに対応しており、ユーザーは自身の興味や好みに合わせて様々な動画を楽しむことができます。  


特筆すべき点として、これらのプラットフォームの中には、視聴に際してアカウントへのログインが必要となるコンテンツや、一部の公式動画が含まれており、それらはnicovideo.lifeのサポート対象外となる場合があることが挙げられます。   

動画を再生する手順はシンプルで、まず視聴したい動画のURLを各プラットフォームからコピーします。  
次に、nicovideo.lifeのウェブサイトにアクセスし、表示されたテキストフィールドにコピーしたURLを貼り付け、「生成」と表示されたボタンをクリックします。  
これにより、VRChatのVideoPlayerで再生可能な専用のURLが生成されます。  
生成されたURLをコピーし、VRChatを起動します。VRChat内のワールドに設置されている動画プレイヤーを選択し、そのURL入力欄に先ほどコピーしたURLをペーストします。  
最後に、動画プレイヤーの再生モードを「Live」または「Stream」に設定することで、動画の再生が開始されます。  
この再生モードの設定は、生成されたURLをVRChatで正しく機能させるために非常に重要です。   

ライブ放送の再生に関しても、基本的な手順は動画再生と同様です。ニコニコ生放送をはじめとする、対応プラットフォームのライブ放送も、動画と同じ手順でVRChat内で視聴することが可能です。   

VRChat内でnicovideo.lifeを利用する際は、上記で説明した動画およびライブ放送の再生方法に従って操作を行います。  
ただし、VRChatのワールドによっては、動画を再生するために特定の動画プレイヤーコンポーネントがワールドの制作者によって設置されている必要がある場合があります。
